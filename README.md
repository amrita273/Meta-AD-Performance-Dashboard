Meta Ads Performance Dashboard - Power BI

Overview
This repository contains a comprehensive Meta Ads Performance Dashboard built using Microsoft Power BI. It provides deep insights into advertising campaigns across Meta platforms (Facebook and Instagram), helping marketers track key performance indicators, analyze audience demographics, and optimize ad spend. 

Key Features
- High-Level KPIs: Track crucial metrics at a glance, including Impressions, Clicks, Engagements, Purchases, and Total Budget.
- Performance Rates: Monitor Click-Through Rate (CTR), Engagement Rate, Conversion Rate, and Purchase Rate.
- Demographic Insights: Includes a breakdown of engagements by gender, distribution across age groups to identify target demographics, and a global map showing engagements by country.
- Trend Analysis: Track engagement patterns over time using weekly and hourly trends, plus a monthly calendar view to analyze performance day-by-day.
- Ad Format Breakdown: Compare the effectiveness of different ad types, such as Video, Stories, Image, and Carousel.
- Dynamic Filtering and Interactivity: Navigate between platforms, change primary metrics dynamically, and use interactive slicers for Campaign Name and Target Interests.

Tools and Technologies Used
- Microsoft Power BI: Data visualization, interactive dashboard creation, and data modeling.
- DAX (Data Analysis Expressions): Used for creating calculated measures, dynamic KPIs, and time intelligence functions.
- Power Query: Data transformation and cleaning.

How to Use
1. Download: Clone this repository or download the .pbix file directly.
2. Open: Open the file using Power BI Desktop.
3. Explore: Interact with the dashboard using the filters on the right pane. Click on specific visuals to cross-filter the rest of the dashboard.
4. Connect Your Own Data: To use this template with your own Meta Ads data, go to Transform Data, update the data source settings to point to your datasets, and click Close and Apply.

Repository Structure
The repository includes the main Power BI dashboard file (.pbix), a preview image of the dashboard, and this project documentation.
